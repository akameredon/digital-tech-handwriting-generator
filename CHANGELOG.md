# Changelog

All notable changes to the Digital Technologies Lesson Note Generator will be documented here.

## [1.0.0] – 2026-11-18

### Added
- Full official NERDC 2025 Digital Technologies schemes for SS1, SS2 and SS3
- Pedagogical prompt engine with strict lesson structure
- Lesson structure validator
- OpenCV-based handwriting preprocessor
- Basic font compiler (fontTools)
- Classmate-style PDF exporter
- FastAPI web service with `/lesson`, `/topics` and `/prompt` endpoints
- CLI tool (`scripts/generate_note.py`) with `--pdf` support
- Bulk term helper (`scripts/bulk_generate.py`)
- Teacher Guide (`docs/TEACHER_GUIDE.md`)
- Basic curriculum and preprocessor tests
- Sample lesson notes for key weeks across SS1–SS3
- Dockerfile, Makefile, pyproject.toml, MIT License, .gitignore

### Sample Notes Included
- SS1: Introduction, History, Number Systems, Hardware, Software, Internet Technologies, Cybersecurity I & II
- SS2: Algorithms, Python, Variables, Control Structures, Data Science, Big Data, AI, Machine Learning, Web Design, Blockchain, Digital Entrepreneurship
- SS3: OOP Basics, SDLC, IoT Applications
