**Class:** SS1  
**Term:** First Term  
**Week:** 5  
**Topic:** Computer Hardware II – Storage Devices and Input/Output Devices

---

**Behavioral Learning Objectives**  
By the end of this lesson, students should be able to:  
1. Distinguish between primary and secondary storage.  
2. List common storage devices and their uses.  
3. Identify common input and output devices.  
4. Explain the difference between input and output.

---

**Key Concepts / Definitions**  
- **Primary storage**: Temporary memory used while the computer is working (RAM).  
- **Secondary storage**: Permanent storage used to keep data (HDD, SSD, flash drive, memory card).  
- **Input device**: Hardware that sends data into the computer (keyboard, mouse, scanner, microphone).  
- **Output device**: Hardware that presents information from the computer (monitor, printer, speakers).

---

**Step-by-Step Conceptual Explanation**  

1. RAM is fast but loses its content when power is switched off.  
2. Hard disks, SSDs and flash drives keep data even when the computer is off.  
3. Input devices allow users to give instructions; output devices show results.  
4. Understanding these devices helps students care for school computers and choose the right tools for tasks.  
5. Modern schools and offices rely heavily on both storage and I/O devices.

---

**Practical / Worked Example**  
Identify on a school computer: the keyboard and mouse (input), the monitor and printer (output), and the hard disk or SSD (secondary storage).

---

**Class Activity / Guided Practice**  
Students list five input devices and five output devices they have used and state one use for each.

---

**End-of-Lesson Quick Test**  
1. What is the difference between primary and secondary storage?  
2. Give two examples of secondary storage.  
3. Name two input devices.  
4. Name two output devices.  
5. True or False: RAM keeps data permanently after the computer is switched off.

---

Draw and label a simple diagram showing the relationship between input devices, the computer (processing + storage), and output devices.
