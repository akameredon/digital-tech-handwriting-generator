**Class:** SS1  
**Term:** First Term  
**Week:** 6  
**Topic:** Computer Software

---

**Behavioral Learning Objectives**  
By the end of this lesson, students should be able to:  
1. Define computer software.  
2. Distinguish between system software and application software.  
3. Give examples of each type of software.  
4. Explain the function of an operating system.

---

**Key Concepts / Definitions**  
- **Software**: The set of instructions that tell the computer what to do.  
- **System software**: Software that manages the computer hardware and provides a platform for application software (e.g. operating systems, device drivers, utilities).  
- **Application software**: Software designed to perform specific tasks for the user (e.g. Microsoft Word, Chrome, WhatsApp).  
- **Operating System (OS)**: The most important system software that controls the overall operation of the computer.

---

**Step-by-Step Conceptual Explanation**  

1. Hardware cannot work without software. Software is the “brain” that gives instructions.  
2. System software works in the background. The operating system is the most important part of system software.  
3. Application software is what students and teachers use daily for writing, calculating, browsing and communicating.  
4. Without an operating system (Windows, macOS, Linux, Android), other programs cannot run.  
5. Understanding the difference helps students choose the right software for a given task.

---

**Practical / Worked Example**  
- Windows 11 or Android → System software (Operating System)  
- Microsoft Word / Google Docs → Application software  
- Antivirus → Utility (system software)  
- Chrome browser → Application software

---

**Class Activity / Guided Practice**  
Students list five software programs they use regularly and classify each as system or application software.

---

**End-of-Lesson Quick Test**  
1. What is software?  
2. Name two types of software.  
3. Give two examples of application software.  
4. What is the main function of an operating system?  
5. True or False: Microsoft Word is system software.
