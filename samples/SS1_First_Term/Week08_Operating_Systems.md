**Behavioral Learning Objectives**  
By the end of this lesson, students should be able to:  
1. Define an operating system.  
2. State the main functions of an operating system.  
3. Give examples of common operating systems.  
4. Distinguish between system software and the operating system.

---

**Key Concepts / Definitions**  
- **Operating System (OS)**: System software that manages computer hardware and software resources and provides common services for computer programs.  
- **Functions of an OS**: Process management, memory management, file management, device management, and user interface.  
- **Examples**: Windows, macOS, Linux, Android, iOS.  
- **User Interface**: The way a user interacts with the computer (Command Line or Graphical User Interface – GUI).

---

**Step-by-Step Conceptual Explanation**  

1. The operating system is the most important system software. Without it, application programs cannot run.  
2. It acts as a bridge between the user and the computer hardware.  
3. When you open a file, the OS locates it on the storage device and loads it into memory.  
4. Modern operating systems provide a graphical interface so that users can click icons instead of typing commands.  
5. Mobile phones also have operating systems (Android and iOS are the most common).

---
