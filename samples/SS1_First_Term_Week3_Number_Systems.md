**Behavioral Learning Objectives**  
By the end of this lesson, students should be able to:  
1. Define the four common number systems used in computing.

3. State the base (radix) of binary, octal, decimal and hexadecimal systems.  
4. Explain why computers use the binary number system.

---

**Key Concepts / Definitions**  
- **Number system**: A way of representing numbers using a set of symbols (digits).  
- **Base (or radix)**: The number of unique digits used in a number system.  
- **Binary (Base 2)**: Uses only 0 and 1.  
- **Decimal (Base 10)**: The everyday system that uses digits 0–9.  
- **Octal (Base 8)**: Uses digits 0–7.  
- **Hexadecimal (Base 16)**: Uses digits 0–9 and letters A–F.  

---

**Step-by-Step Conceptual Explanation**  

1. Humans normally count in tens (decimal) because we have ten fingers.  
2. Computers can only understand two states: ON and OFF. These two states are represented by 1 and 0. That is why computers use the binary number system.  
3. Binary is the foundation of all digital technology. Every picture, song, video and document inside a computer is finally stored as a long series of 0s and 1s.  
4. Because binary numbers become very long, computer scientists also use octal (groups of 3 bits) and hexadecimal (groups of 4 bits) to make the numbers shorter and easier to read.  
5. Hexadecimal is especially common when we talk about memory addresses and colours in web design (e.g. #FF0000 for pure red).  

**Conversion Examples**

Decimal 13 → Binary  
13 ÷ 2 = 6 remainder 1  
6 ÷ 2 = 3 remainder 0  
3 ÷ 2 = 1 remainder 1  
1 ÷ 2 = 0 remainder 1  
Reading remainders from bottom to top → **1101₂**

Binary 1011 → Decimal  
1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8 + 0 + 2 + 1 = **11₁₀**
