**Class:** SS1  
**Term:** Second Term  
**Week:** 2  
**Topic:** Internet Technologies

---

**Behavioral Learning Objectives**  
By the end of this lesson, students should be able to:  
1. Define the Internet.  
2. Explain the difference between the Internet and the World Wide Web.  
3. List common Internet services.  
4. Use a search engine effectively to find information.

---

**Key Concepts / Definitions**  
- **Internet**: A global network of interconnected computers that communicate using standard protocols.  
- **World Wide Web (WWW)**: A system of interlinked hypertext documents accessed via the Internet.  
- **Web browser**: Software used to access and view websites (e.g. Chrome, Firefox, Edge).  
- **Search engine**: A tool that helps users find information on the web (e.g. Google, Bing).  
- **URL**: Uniform Resource Locator – the address of a resource on the Internet.

---

**Step-by-Step Conceptual Explanation**  

1. The Internet is the infrastructure (the network of computers and cables). The World Wide Web is one of the services that runs on the Internet.  
2. Other Internet services include email, file transfer, video calls and online banking.  
3. To access websites, we use a web browser and type a URL or use a search engine.  
4. Good search skills help students find reliable information for assignments and research.  
5. In Nigeria, the Internet has become essential for education, business, banking and communication.

---

**Practical / Worked Example**  
Open a browser and search for “NERDC curriculum Digital Technologies”. Compare the results from Google and Bing. Identify which results look most reliable (official websites, education sites).

---

**Class Activity / Guided Practice**  
Students practise searching for three school-related topics and write down the title and URL of the best result for each.

---

**End-of-Lesson Quick Test**  
1. What is the Internet?  
2. What is the difference between the Internet and the World Wide Web?  
3. Name two web browsers.  
4. What does URL stand for?  
5. True or False: Email is a service that runs on the Internet.
