**Class:** SS1  
**Term:** Second Term  
**Week:** 8  
**Topic:** Cybersecurity II – Protection Methods

---

**Behavioral Learning Objectives**  
By the end of this lesson, students should be able to:  
1. List practical ways to protect computers and personal data.  
2. Explain the importance of strong passwords.  
3. Describe the function of antivirus software and firewalls.  
4. Apply basic safe online habits.

---

**Key Concepts / Definitions**  
- **Antivirus software**: A program that detects, prevents and removes malware.  
- **Firewall**: A security system that monitors and controls incoming and outgoing network traffic.  
- **Strong password**: A password that is long, uses a mix of letters, numbers and symbols, and is not easy to guess.  
- **Two-factor authentication (2FA)**: An extra layer of security that requires a second form of verification.  
- **Update**: Installing the latest security patches for software and operating systems.

---

**Step-by-Step Conceptual Explanation**  

1. Prevention is better than cure. Most cyber attacks succeed because of weak passwords or outdated software.  
2. A strong password should be at least 12 characters and unique for each important account.  
3. Antivirus software should be kept updated and run regular scans.  
4. Firewalls act like a security gate between your device and the Internet.  
5. Students should avoid clicking unknown links, downloading software from untrusted sites, and sharing personal information carelessly.

---

**Practical / Worked Example**  
Examples of weak vs strong passwords:  
- Weak: `123456`, `password`, `chinedu2024`  
- Strong: `Tr3e$Horse!Lagos99`

Enable 2FA on email and social media accounts whenever possible.

---

**Class Activity / Guided Practice**  
Students create three strong passwords (on paper) and explain why each one is strong. Teacher reviews them without collecting the actual passwords.

---

**End-of-Lesson Quick Test**  
1. Name two protection tools used in cybersecurity.  
2. What makes a password strong?  
3. What is the function of a firewall?  
4. Why should software be updated regularly?  
5. True or False: Using the same password for all accounts is safe.
