---

**Behavioral Learning Objectives**  
By the end of this lesson, students should be able to:  
1. Define a spreadsheet.  
2. Identify the main parts of a spreadsheet window (rows, columns, cells).  
3. Enter data and simple formulas.  
4. Use basic cell referencing.

---

**Key Concepts / Definitions**  
- **Spreadsheet**: An application used for organising, calculating and analysing data in a tabular form.  
- **Cell**: The intersection of a row and a column (e.g. A1, B5).  
- **Row**: Horizontal line of cells identified by numbers.  
- **Column**: Vertical line of cells identified by letters.  
- **Formula**: An expression that calculates a value (always begins with =).  
- **Cell reference**: The address of a cell (e.g. A1).

---

**Step-by-Step Conceptual Explanation**  

1. Spreadsheets (Microsoft Excel, Google Sheets) are used for calculations, budgets, student results and data analysis.  
2. Data is entered into cells. Each cell has a unique address.  
3. Formulas allow automatic calculations. If the data changes, the result updates automatically.  
4. Simple formulas use operators such as + (add), – (subtract), * (multiply) and / (divide).  
5. Understanding spreadsheets is a valuable skill for both school and future work.
