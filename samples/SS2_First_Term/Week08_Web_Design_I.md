**Topic:** Web Design I – Introduction to HTML and CSS

---

**Behavioral Learning Objectives**  
By the end of this lesson, students should be able to:  
1. Define HTML and CSS.  
2. Explain the difference between HTML and CSS.  
3. Write a simple HTML page with basic tags.  
4. Apply simple CSS styling to change colour and font size.

---

**Key Concepts / Definitions**  
- **HTML (HyperText Markup Language)**: The standard language used to create the structure of web pages.  
- **CSS (Cascading Style Sheets)**: The language used to style and design the appearance of web pages.  
- **Tag**: A keyword enclosed in angle brackets that tells the browser how to display content (e.g. `<h1>`, `<p>`).  
- **Element**: A complete tag pair with content inside (e.g. `<p>This is a paragraph</p>`).

---

**Step-by-Step Conceptual Explanation**  

1. Every website you visit is built with HTML for structure and CSS for design.  
2. HTML tells the browser “this is a heading”, “this is a paragraph”, “this is an image”.  
3. CSS tells the browser “make the heading blue”, “make the text larger”, “add space around the paragraph”.  
4. Separating structure (HTML) from design (CSS) makes websites easier to maintain.  
5. In Nigeria, many young people learn HTML and CSS as their first step into web development and freelancing.

---

**Practical / Worked Example**

```html
<!DOCTYPE html>
<html>
<head>
    <title>My First Web Page</title>
    <style>
        h1 { color: darkblue; }
        p { font-size: 18px; }
    </style>
</head>
<body>
    <h1>Welcome to Digital Technologies</h1>
    <p>This is my first web page created in SS2.</p>
</body>
</html>
```

---

**Class Activity / Guided Practice**  
Students type the example above into a text editor, save it as `index.html`, and open it in a browser. Then they change the colour of the heading and the size of the paragraph.
