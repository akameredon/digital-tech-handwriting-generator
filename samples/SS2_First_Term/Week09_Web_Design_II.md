**Class:** SS2  
**Term:** First Term  
**Week:** 9  
**Topic:** Web Design II – Creating Simple Websites

---

**Behavioral Learning Objectives**  
By the end of this lesson, students should be able to:  
1. Structure a multi-page simple website using HTML.  
2. Link pages together with anchor tags.  
3. Apply basic CSS for colour, font and layout.  
4. Save and open the website in a browser.

---

**Key Concepts / Definitions**  
- **Hyperlink**: A clickable link that takes the user to another page or section.  
- **Navigation**: The menu or links that help users move around a website.  
- **Home page**: The main starting page of a website (usually `index.html`).  
- **External CSS**: CSS written in a separate `.css` file and linked to HTML pages.

---

**Step-by-Step Conceptual Explanation**  

1. A simple website usually has a home page and a few other pages (About, Contact, etc.).  
2. Pages are linked using the `<a href="...">` tag.  
3. Using a separate CSS file keeps design consistent across all pages.  
4. Students can create personal portfolios, class project sites or small school club websites.  
5. These skills are the foundation of web development and freelancing opportunities.

---

**Practical / Worked Example**

`index.html`
```html
<!DOCTYPE html>
<html>
<head>
  <title>My School Club</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Digital Technologies Club</h1>
  <a href="about.html">About Us</a>
  <p>Welcome to our club website.</p>
</body>
</html>
```

---

**Class Activity / Guided Practice**  
Students create two linked pages (Home and About) with shared CSS styling.

---

**End-of-Lesson Quick Test**  
1. What is a hyperlink?  
2. What is the usual name of the home page file?  
3. Why is external CSS useful?  
4. Write the HTML tag used to link to another page.  
5. True or False: A website can only have one page.

---

**Assignment**  
Create a simple three-page website about yourself or your school club. Include a home page, an about page, and a contact page. Link them together and apply basic CSS.
