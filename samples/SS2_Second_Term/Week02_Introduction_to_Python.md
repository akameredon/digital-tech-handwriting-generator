**Behavioral Learning Objectives**  
By the end of this lesson, students should be able to:  
1. Define Python as a high-level, interpreted programming language.  
2. State at least three reasons why Python is widely used.  
3. Write and execute a simple Python program that displays text.  
4. Identify comments and the print() function in a Python script.

---

**Key Concepts / Definitions**  
- **Python**: A high-level, general-purpose, interpreted programming language created by Guido van Rossum.  
- **High-level language**: Close to human language, far from machine code.  
- **Interpreted language**: Code is executed line by line by an interpreter.  
- **Syntax**: Rules that define how a program must be written.  
- **print()**: Built-in function used to display output.

---

**Step-by-Step Conceptual Explanation**  

1. Python was created by Guido van Rossum and first released in 1991.  
2. It was designed to be easy to read and write.  
3. Because Python is interpreted, students can write a line of code and see the result immediately.  
4. Python is used in web development, data analysis, artificial intelligence, automation, and education.  
5. In Nigerian secondary schools, Python is an excellent first language because of its simple syntax.  
6. Python programs are saved with the `.py` extension.
