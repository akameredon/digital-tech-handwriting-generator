**Class:** SS3  
**Term:** First Term  
**Week:** 4  
**Topic:** Software Development Life Cycle (SDLC)

---

**Behavioral Learning Objectives**  
By the end of this lesson, students should be able to:  
1. Define the Software Development Life Cycle (SDLC).  
2. List the main phases of the SDLC.  
3. Explain the purpose of each phase.  
4. Distinguish between the Waterfall and Agile models.

---

**Key Concepts / Definitions**  
- **SDLC**: A structured process used to design, develop and test high-quality software.  
- **Waterfall model**: A linear sequential approach where each phase must be completed before the next begins.  
- **Agile model**: An iterative approach that delivers working software in small increments and responds quickly to change.  
- **Phases of SDLC**: Requirement gathering, Design, Implementation (Coding), Testing, Deployment, Maintenance.

---

**Step-by-Step Conceptual Explanation**  

1. Building software is like building a house – you need a clear plan and ordered stages.  
2. The SDLC provides that plan so that software is reliable, meets user needs and can be maintained.  
3. In the Waterfall model, progress flows in one direction (like a waterfall). It is simple but inflexible.  
4. Agile is preferred for modern projects because requirements often change and users want early results.  
5. Nigerian software developers and startups commonly use Agile methods for apps and web systems.

---

**Practical / Worked Example**  
Imagine developing a school result management system:  
1. Requirement gathering – talk to teachers and the exam officer.  
2. Design – plan the database and screens.  
3. Coding – write the program.  
4. Testing – check for errors.  
5. Deployment – install it in the school.  
6. Maintenance – fix issues and add new features later.

---

**Class Activity / Guided Practice**  
Students work in groups to list the six SDLC phases and give one activity that happens in each phase for a simple mobile app.

---

**End-of-Lesson Quick Test**  
1. What does SDLC stand for?  
2. Name three phases of the SDLC.  
3. What is the main difference between Waterfall and Agile?  
4. Why is testing important?  
5. True or False: In the Waterfall model you can easily go back to previous phases.
