**Term:** First Term

**Topic:** Networking II – IP Addressing, Subnetting and Protocols

---

**Behavioral Learning Objectives**  
By the end of this lesson, students should be able to:  
1. Explain what an IP address is.  
2. Distinguish between IPv4 and IPv6 (basic level).  
3. Define a protocol and give common examples.  
4. State the purpose of subnetting in simple terms.

---

**Key Concepts / Definitions**  
- **IP Address**: A unique numerical label assigned to each device on a network.  
- **IPv4**: The older 32-bit address format (e.g. 192.168.1.1).  
- **IPv6**: The newer 128-bit address format designed to provide more addresses.  
- **Protocol**: A set of rules that devices follow to communicate (e.g. TCP, IP, HTTP, HTTPS).  
- **Subnetting**: Dividing a large network into smaller networks for better management and security.

---

**Step-by-Step Conceptual Explanation**  

1. Every device on a network needs an address so that data can find it (just like a house address).  
2. IPv4 addresses are running out, which is why IPv6 was introduced.  
3. Protocols ensure that devices from different manufacturers can understand each other.  
4. HTTP and HTTPS are the protocols used for web browsing; HTTPS is secure.  
5. Understanding these basics is important for networking, cybersecurity and further computer science studies.

---

**Practical / Worked Example**  
On a computer, open the command prompt or terminal and type `ipconfig` (Windows) or `ifconfig` / `ip addr` (Linux/Mac) to see the device’s IP address.

---

**Class Activity / Guided Practice**  
Students find the IP address of the school lab computers or their phones (where possible) and classify whether it looks like a private or public address.

---

**End-of-Lesson Quick Test**

2. Give one example of an IPv4 address.  
3. What is a protocol?  
4. Name two common protocols.  
5. True or False: All devices on the Internet share the same IP address.
