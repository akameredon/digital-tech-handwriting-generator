**Class:** SS3  
**Term:** Second Term  
**Week:** 1  
**Topic:** Advanced Web Design – JavaScript & Responsive Design

---

**Behavioral Learning Objectives**  
By the end of this lesson, students should be able to:  
1. Explain the role of JavaScript in web pages.  
2. Write simple JavaScript statements that respond to user actions.  
3. Define responsive design.  
4. State why responsive design is important for mobile users.

---

**Key Concepts / Definitions**  
- **JavaScript**: A programming language that adds interactivity to web pages.  
- **Event**: An action that happens in the browser (e.g. click, mouseover).  
- **Responsive Design**: Designing websites so that they look and work well on different screen sizes (phones, tablets, desktops).  
- **Viewport**: The visible area of a web page on a device.

---

**Step-by-Step Conceptual Explanation**  

1. HTML provides structure, CSS provides style, and JavaScript provides behaviour.  
2. With JavaScript we can change content, validate forms, and respond to clicks without reloading the page.  
3. Many Nigerians access the internet mainly through phones, so websites must work well on small screens.  
4. Responsive design uses flexible layouts and media queries so that the same website adapts to different devices.  
5. Understanding these concepts prepares students for modern web development.

---

**Practical / Worked Example**

```html
<button onclick="alert('Welcome to Digital Technologies!')">
  Click Me
</button>
```

```css
/* Simple responsive idea */
@media (max-width: 600px) {
  body { font-size: 14px; }
}
```

---

**Class Activity / Guided Practice**  
Students add a button to a simple HTML page that displays a message when clicked, and discuss how the page looks on a phone versus a computer.

---

**End-of-Lesson Quick Test**  
1. What is the main purpose of JavaScript?  
2. What is responsive design?  
3. Why is responsive design important in Nigeria?

**Assignment**
